# Medical MCQ Generation System - Plan v2.1
## Provenance-First Knowledge Graph Pipeline - Implementation Guide

---

## 0) Core Objectives

**Build a provenance-first pipeline with zero hallucinations:**
- Every KG triple MUST have exact evidence sentence(s) + source citation (PMID/DOI)
- Refuse to generate MCQs if evidence is unavailable
- All MCQ explanations include verbatim evidence text + citation

**Use Case:** Generate single-best-answer medical MCQs for FRACS neurosurgery training with doctor review and refinement.

**Scale:** Proof of concept with <20 PDFs

---

## 1) Pipeline Architecture

```
PDF → Sentence Split → Negation Detect → NER → 
Canonicaliser (LLM) → Relation Extract → Relation Verify (LLM) → 
Schema Validate → SQLite → MCQ Generate (LLM) → 
Human Review (INTERRUPT) → Final Output
```

**Key Node Functions:**
- **Negation Detector**: Filter "no evidence of tumor" before expensive LLM calls (regex first, LLM fallback)
- **Canonicaliser**: Normalize "MI" / "myocardial infarction" / "heart attack" → single canonical concept
- **Relation Verifier**: LLM validates that evidence truly supports extracted triple (confidence ≥ 0.6)
- **Human Review**: LangGraph interrupt for doctor approval/editing via Gradio UI

---

## 2) Key Design Decisions

### Provenance System
- **Multi-sentence evidence**: Allow up to 3 consecutive sentences (medical relationships often span sentences)
- **Hard FK constraints**: Use SQLite foreign keys + CHECK constraints to prevent orphaned data
- **Section tracking**: Store which section (Results/Discussion/Methods) evidence came from for quality assessment
- **No UNIQUE on triples**: Same relationship from multiple papers creates separate evidence rows

**Rationale:** DB-level enforcement prevents bugs from corrupting provenance guarantee

### Entity Model
**Separate canonical concepts from mentions:**
```
concepts(canonical_id, canonical_name, semantic_category)
entities(entity_id, canonical_id, doc_id, page, sent_idx, span_text)
```
**Rationale:** One concept can have many mentions across documents; cleaner than mixed model

### Caching Strategy
- **Normalize on-demand**: Store only verbatim text in DB; normalize (lowercase, strip spaces) only for cache key generation
- **xxhash for speed**: 10x faster than MD5, same collision resistance
- **Cache key**: `operation:xxhash(normalized_content)`

**Rationale:** Saves storage vs storing both normalized + verbatim; good enough for PoC

### Document Handling
- **SHA256 deduplication**: Hash file content (not name) to skip duplicate PDFs
- **Page numbers**: Track page for PDF navigation in review UI
- **SQLite WAL mode**: Allows concurrent reads during writes (critical for Gradio UI)

### Cost Control
- **LLM call budgets**: 50 calls/doc max, 30 triples/doc cap
- **Early negation filtering**: Pattern matching before LLM calls
- **Aggressive caching**: Cache all canonicalization + verification calls
- **Dry-run mode**: Preview costs before execution

**Estimated PoC cost:** ~$0.11 for 20 PDFs with 65% cache hit rate

### NCBI Rate Limiting
- **With API key**: 6 requests/second (360/min) - NOT 3 req/min as originally stated
- **Requires**: NCBI_API_KEY + email in config
- **Backoff**: [0.5, 1, 2, 4] seconds on errors

### Feature Flags
```yaml
features:
  extract_microbe: false  # Enable later for antibiotic questions
  dry_run: false
```
**Rationale:** Deploy schema now, defer expensive extraction until core validated

## 4) Database Schema (SQLite)

**Critical Pragmas:**
```sql
PRAGMA foreign_keys = ON;      -- Enforce referential integrity
PRAGMA journal_mode = WAL;     -- Concurrent reads during writes
```

**Key Tables:**
```sql
-- Documents with deduplication
CREATE TABLE docs (
    doc_id INTEGER PRIMARY KEY,
    source_kind TEXT CHECK(source_kind IN ('PUBMED_ABSTRACT','PMC_FULLTEXT','LOCAL_PDF')),
    pmid TEXT, doi TEXT,
    sha256 TEXT UNIQUE NOT NULL,    -- Content hash for deduplication
    created_at TIMESTAMP
);

-- Canonical concepts
CREATE TABLE concepts (
    canonical_id INTEGER PRIMARY KEY,
    canonical_name TEXT NOT NULL,
    semantic_category TEXT CHECK(...),  -- DISORDER, DRUG, PROCEDURE, etc.
    llm_conf REAL
);

-- Entity mentions (link to concepts)
CREATE TABLE entities (
    entity_id INTEGER PRIMARY KEY,
    canonical_id INTEGER REFERENCES concepts(canonical_id),
    doc_id INTEGER REFERENCES docs(doc_id),
    page INTEGER,                   -- PDF page number
    sent_idx INTEGER, char_start INTEGER, char_end INTEGER,
    span_text TEXT
);

-- Triples (NO UNIQUE constraint)
CREATE TABLE triples (
    triple_id INTEGER PRIMARY KEY,
    head_entity INTEGER REFERENCES entities(entity_id),
    rel_id TEXT REFERENCES relations(rel_id),
    tail_entity INTEGER REFERENCES entities(entity_id),
    confidence REAL,
    verifier_model TEXT, prompt_id INTEGER,
    created_at TIMESTAMP
);

-- Evidence with multi-sentence support
CREATE TABLE evidence (
    evidence_id INTEGER PRIMARY KEY,
    triple_id INTEGER REFERENCES triples(triple_id) ON DELETE CASCADE,
    doc_id INTEGER REFERENCES docs(doc_id),
    section TEXT,                   -- Results/Methods/Discussion
    sent_start INTEGER, sent_end INTEGER,  -- Inclusive range
    sentence_text TEXT NOT NULL,    -- Verbatim only (normalize on-demand)
    CHECK(sent_end - sent_start < 3)
);

-- MCQs
CREATE TABLE mcqs (
    mcq_id INTEGER PRIMARY KEY,
    triple_id INTEGER REFERENCES triples(triple_id) ON DELETE CASCADE,
    stem TEXT,
    options_json TEXT,              -- 5 options, 1 correct
    explanation TEXT,
    citations_json TEXT,
    topic TEXT, difficulty TEXT,
    status TEXT DEFAULT 'pending',  -- pending/approved/rejected/needs_review
    human_feedback TEXT
);

-- Cache
CREATE TABLE cache (
    cache_key TEXT PRIMARY KEY,     -- xxhash of normalized content
    cache_value TEXT,               -- JSON result
    cache_type TEXT,                -- canonicalization/verification
    hit_count INTEGER DEFAULT 0
);
```

**Invariant:** Every triple_id has ≥1 evidence row; negated mentions excluded

## 7) MCQ Generation Policy

**Format:** 5 options (1 correct + 4 distractors), citation in explanation only

**Hard Rules:**
1. Exactly 1 correct answer (single-best-answer)
2. All options same semantic type (all drugs OR all diseases, not mixed)
3. Citation mandatory: "PMID:XXX" or "DOI:XXX" in explanation
4. Verbatim evidence sentence quoted in explanation
5. Distractors must NOT token-match evidence text

**Validation Example:**
```python
# Check evidence leakage
evidence_tokens = set(evidence.sentence_text.lower().split())
for distractor in mcq.options:
    if not distractor.is_correct:
        overlap = set(distractor.text.lower().split()) & evidence_tokens
        if len(overlap) > 2:  # Allow small function words
            raise ValidationError("Distractor leaks evidence")
```

**Failure Handling:**
- Invalid MCQs → review queue with error details
- Missing citation → auto-reject, regenerate
- Type mismatch → regenerate distractors only
- Evidence leakage → regenerate affected distractors

## 9) Caching Implementation

```python
import xxhash
import re

def normalize_text(text: str) -> str:
    """Normalize for caching only (don't store)"""
    text = re.sub(r'\[\d+(?:-\d+)?\]', '', text)  # Remove citations
    text = text.lower()
    text = re.sub(r'\s+', ' ', text).strip()
    return text

def get_cache_key(operation: str, content: str, context: str = None) -> str:
    normalized = normalize_text(content)
    if context:
        normalized += "|" + normalize_text(context)
    hash_val = xxhash.xxh64(normalized).hexdigest()
    return f"{operation}:{hash_val}"

# Usage
cache_key = get_cache_key("canonicalization", span_text, sentence)
result = cache_get(cache_key) or llm_call_and_cache(...)
```

## 11) Failure Modes & Handling

**Case: Verifier rejects all triples**
- 0 candidates → skip document (unsuitable content)
- <3 verified triples → flag for review queue
- >10 low-confidence → flag for threshold tuning

**Case: NCBI rate limit (429 error)**
- Retry with exponential backoff: [0.5, 1, 2, 4] seconds
- Max 3 retries, then fail with error log

**Case: PDF parsing fails**
- Try pypdf first
- Fallback to OCR (if tesseract available)
- If both fail → log error, skip document

**Case: LLM validation error**
- Retry on RateLimitError, APIError
- Don't retry on AuthenticationError
- Log all errors with context

## 13) Cost Estimation Formula

```python
# Per document estimate
sentences = doc_length / 8  # ~8 words/sentence
entities = sentences / 8     # ~1 entity per 8 sentences
triples = entities / 3       # ~1 triple per 3 entities
mcqs = min(triples, 30)      # Cap at 30

# LLM calls
canon_calls = entities
verify_calls = triples * 2
mcq_calls = mcqs

# Costs (gpt-4o-mini @ $0.00015 per call avg)
canon_cost = canon_calls * 0.00015
verify_cost = verify_calls * 0.00015
mcq_cost = mcq_calls * 0.0005  # gpt-4o for MCQs

# With 65% cache hit after first doc
total = (canon_cost + verify_cost + mcq_cost) * (1 - 0.65 if doc_num > 1 else 1)
```

**20 PDFs estimate:** $0.11 total
